# 🗣️ Presentación y Defensa Técnica

## ¿Qué es este apartado?
Este espacio almacena el material de apoyo visual y argumentativo diseñado para la exposición del proyecto integrador. La presentación sintetiza todo el proceso de desarrollo —desde la investigación y el diseño, hasta la construcción y validación— y está estructurada para defender las decisiones de ingeniería tomadas por el equipo ante los evaluadores o clientes.

## Archivos en este directorio
En esta carpeta se subirán los archivos de diapositivas (`.pptx`, `.pdf`) o el documento final que se proyectará durante la defensa técnica presencial del proyecto.
