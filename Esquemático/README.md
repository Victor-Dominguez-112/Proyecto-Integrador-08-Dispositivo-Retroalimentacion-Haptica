# 🔌 Esquemático

## ¿Qué es este apartado?
El esquemático es el plano técnico y detallado del circuito electrónico. A diferencia del diagrama de bloques, aquí se especifican las conexiones exactas pin a pin, los valores preliminares de los componentes, la ubicación de las tierras (GND), las fuentes de alimentación de bajo voltaje y los elementos de protección. 

Este diagrama muestra cómo interactúan el temporizador NE555, el transistor BJT, los diodos de protección (incluyendo el diodo flyback para el motor) y los indicadores LED.
