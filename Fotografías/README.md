# 📸 Fotografías

## ¿Qué es este apartado?
Este apartado sirve como bitácora visual de la fase de construcción. El objetivo es documentar el ensamblaje físico del circuito en la protoboard o placa experimental. 

Las imágenes aquí alojadas permitirán evaluar criterios importantes de ingeniería como la organización del cableado, la correcta distribución de los componentes y las medidas de seguridad eléctrica implementadas en el prototipo físico.

## Archivos en este directorio
En esta carpeta se subirán fotografías en alta resolución (`.jpg`, `.png`) del circuito desde diferentes ángulos, mostrando detalles específicos como el cableado del motor, la posición del transistor y la alimentación del sistema.
