# 🎥 Video Demostrativo

## ¿Qué es este apartado?
El video demostrativo es la prueba audiovisual final del funcionamiento del sistema. Tiene una duración estricta de 3 a 5 minutos y su propósito es mostrar el dispositivo de retroalimentación háptica operando en tiempo real. 

En este espacio se documenta cómo el usuario interactúa con los pulsadores/interruptores, cómo responde el motor vibrador simulando la "máquina de toques" de manera segura y cómo actúan los indicadores visuales y sonoros.

## Archivos en este directorio
Debido a los límites de peso de los repositorios, en esta carpeta se subirá un archivo de texto con el enlace directo (link) a la plataforma donde esté alojado el video (como YouTube o Google Drive), o bien un archivo de video comprimido (`.mp4`) si el tamaño lo permite.
