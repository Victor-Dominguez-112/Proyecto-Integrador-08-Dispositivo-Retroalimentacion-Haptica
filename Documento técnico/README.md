# 📄 Documento Técnico

## ¿Qué es este apartado?
El documento técnico es el reporte formal y extenso que consolida toda la información del proyecto integrador. A diferencia de los otros directorios que se enfocan en entregables muy específicos (como solo cálculos o solo diagramas), este documento entrelaza la investigación, el diseño, la simulación, la construcción y la validación en una narrativa de ingeniería completa y estructurada.

Aquí se detalla a profundidad cómo el dispositivo de retroalimentación háptica resuelve la situación problema, justificando las decisiones de diseño analógico para cumplir con los objetivos y asegurando que el sistema sea completamente seguro para el usuario.

## Archivos en este directorio
En esta carpeta se subirá el archivo final del reporte de ingeniería (generalmente en formato `.pdf` o `.docx`). Este archivo suele incluir la portada, introducción, marco teórico, el desarrollo de las 6 fases del proyecto, las conclusiones del equipo y las referencias bibliográficas.
