## 📖 1. Situación Problema y Objetivo
Este proyecto consiste en el diseño, análisis, simulación, construcción y validación de un dispositivo portátil de retroalimentación háptica. El sistema simula la experiencia de una "máquina de toques" utilizando un motor vibrador en lugar de descargas eléctricas, garantizando un entorno seguro para los usuarios.

**Objetivo General:** Controlar un motor vibrador mediante electrónica analógica, utilizando un temporizador y una etapa de potencia.
