# 📋 Lista de Materiales (BOM)

## ¿Qué es este apartado?
La Lista de Materiales o BOM (Bill of Materials) es el inventario detallado de todos los componentes físicos, herramientas y consumibles necesarios para llevar el diseño del simulador a la realidad. 

Sirve para tener un control exacto de lo que se debe adquirir antes de la etapa de construcción y asegura que se cumplan las restricciones del proyecto (uso de motor vibrador DC, NE555, transistor BJT, diodos, etc.).

## Archivos en este directorio
En esta carpeta se alojará la tabla con la lista de componentes, detallando cantidades, descripciones, valores técnicos y sus designadores de referencia (ej. $R_1$, $C_1$, $U_1$). Se subirá en formato Markdown tabular o mediante un archivo de hoja de cálculo (`.csv`, `.xlsx`).
