# 🧩 Diagrama de Bloques

## ¿Qué es este apartado?
El diagrama de bloques es una representación visual de alto nivel que ilustra la arquitectura general del dispositivo de retroalimentación háptica. Su propósito es mostrar el flujo de la señal y la interacción entre las diferentes etapas del sistema sin entrar en detalles de componentes eléctricos específicos.

El flujo básico documentado aquí abarca:
1.  **Etapa de Entrada:** Selección del modo por parte del usuario.
2.  **Etapa de Temporización / Control:** Circuito integrado NE555.
3.  **Etapa de Potencia:** Transistor BJT.
4.  **Etapa de Salida:** Motor vibrador e indicadores visuales.

## Archivos en este directorio
En esta carpeta se subirán los archivos de imagen (formatos `.png`, `.jpg` o `.pdf`) que contienen el diagrama de bloques finalizado, así como cualquier archivo fuente utilizado para su creación (por ejemplo, diagramas de draw.io o Lucidchart).
