# 📊 Tabla de Mediciones

## ¿Qué es este apartado?
Este directorio está destinado a la validación experimental del proyecto. Contiene el análisis comparativo entre lo que se calculó en teoría, lo que se observó en la simulación y lo que realmente ocurrió al medir el circuito físico con instrumentación (multímetro, osciloscopio, termómetro).

Es fundamental para calcular el porcentaje de error y justificar las variaciones físicas (como la tolerancia de las resistencias o las caídas reales de tensión en los semiconductores).

## Archivos en este directorio
En esta carpeta se subirá la tabla comparativa final. Puede ser un archivo directo en Markdown, un PDF o una hoja de cálculo con los registros de los tiempos de vibración, corriente del motor, temperatura del transistor y el consumo total del sistema.
