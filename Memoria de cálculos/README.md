# 🧮 Memoria de Cálculos

## ¿Qué es este apartado?
La memoria de cálculos contiene la justificación matemática y teórica que respalda el diseño del circuito. Aquí se demuestra que los componentes seleccionados operarán dentro de sus márgenes de seguridad y cumplirán con los parámetros del problema de ingeniería.

Los cálculos detallados aquí incluyen:
*   Tiempos de activación y constante $RC$ del NE555.
*   Corriente demandada por el motor vibrador.
*   Análisis de mallas para las corrientes de base ($I_B$) y colector ($I_C$) del transistor.
*   Cálculo de la potencia disipada para evitar sobrecalentamientos.
*   Estimación del consumo total de la fuente de alimentación.

## Archivos en este directorio
En esta carpeta se subirán los documentos (`.pdf`, archivos de Mathcad, o el mismo `README.md` extendido con fórmulas en LaTeX) que contienen todo el desarrollo matemático paso a paso.
