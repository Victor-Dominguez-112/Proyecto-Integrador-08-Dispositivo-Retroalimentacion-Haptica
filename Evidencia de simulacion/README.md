# 💻 Evidencia de Simulación

## ¿Qué es este apartado?
La simulación es el paso previo al ensamblaje físico. Permite validar de manera virtual que el circuito esquemático y los cálculos teóricos funcionan correctamente en conjunto. Aquí se verifica el comportamiento del temporizador, la conmutación de la etapa de potencia y la correcta activación de la carga (motor) sin riesgo de dañar componentes reales.

## Archivos en este directorio
En esta carpeta se subirán:
*   Los archivos ejecutables/fuente del software de simulación (Proteus, LTspice, Multisim, etc.).
*   Capturas de pantalla mostrando mediciones virtuales (osciloscopios, amperímetros y voltímetros virtuales).
*   GIFs o videos cortos evidenciando el circuito en funcionamiento.
